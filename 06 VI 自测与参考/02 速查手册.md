## 29.1 核心RL 与对齐公式

PPO Clip: L = E[min(rt ˆAt, clip(rt, 1±ϵ) ˆAt)], rt = πθ(at|st)/πold(at|st) (29.1)

DPO: L = −E[log σ(β log πθ(yw|x) πref(yw|x) −β log πθ(yl|x) πref(yl|x))] (29.2)

GRPO: ˆAi = (ri −µG)/σG, then PPO clip update (no critic) (29.3)

KTO: L = λw(1 −v(yw)) + λl · v(yl), v = σ(β log(πθ/πref) −z) (29.4)

IPO: L = E[(log(πθ(yw)/πref(yw)) −log(πθ(yl)/πref(yl)) −1/(2β))2] (29.5)

ORPO: L = LSFT(yw) −λ log σ(log(odds(yw)/odds(yl))) (29.6) ˆAt = PT−t GAE: l=0 (γλ)lδt+l, δt = rt + γV (st+1) −V (st) (29.7)

KL Penalty: Rtotal = rϕ(x, y) −βDKL[πθ(y|x)∥πref(y|x)] (29.8)

RM (Bradley-Terry): L = −E[log σ(rϕ(x, yw) −rϕ(x, yl))] (29.9)

Best-of-N: y∗= arg yi∼πθ(·|x), i=1..N rϕ(x, yi) max (29.10)

## 29.13 方法选择决策树

1. 是否有成对偏好数据（chosen + rejected）？

- 标签噪声大→IPO

- 显存受限、尚未做SFT →ORPO

- 数据干净、算力有限→DPO

- DPO 进入瓶颈、希望加入探索→Online DPO

2. 只有二值反馈（点赞/ 点踩）？→KTO

3. 有可验证奖励（数学/ 代码）？→GRPO

4. 不惜代价追求最高质量？→PPO

5. 想要免训练的改进？→Best-of-N
